## What shipped

### Data: `Todo.DoneAt` (`store.go`)

- `DoneAt time.Time \`json:"doneAt,omitzero"\`` is a value, not a pointer. With
  `omitzero` (Go 1.24+; go.mod is 1.26.1) the zero value stays out of the file, and
  readers call `IsZero()` without a nil check. Untouched backlogs stay
  byte-identical, which satisfies the todos.json compat contract.
- It is stamped with `time.Now()`, so the JSON carries the local wall clock plus its
  offset (`…T14:05:00-05:00`). Readers still call `.Local()` before drawing,
  because the machine reading a backlog may be in another zone.
- Lifecycle:
  - `toggle`: stamps on completion and clears on reopen.
  - `setDone(true)`: stamps. Its existing idempotent early return means a repeat
    auto-complete (e.g. after a drop) never moves the stamp forward.
    `setDone(false)` clears it.
  - `freeze`: clears it along with `Done`, because the stamp goes with the claim
    it records.
- It is a record, not an order. Completion order still lives in the array
  (`fileAsLatestDone`), so reordering done todos by hand is not undone by a sort.

### Display

- **Row** (`ui.go` `rebuildList`): done rows get a `descMark`, `done <compact>`, in
  the slot the ⏰ fire time would hold. A done todo never has a schedule, so the
  two never compete. Todos completed before the field existed draw no mark.
- **`formatDoneTime`** (`schedule.go`): `formatScheduleTime`'s ladder (`15:04` /
  `Mon 15:04` / `Jan 2 15:04`) plus one rung. A completion from a different year
  gets `2006-01-02 15:04`, because a stamp from last year without its year would
  read as this year's.
- **Prompt view** (`viewPrompt` meta line): `done 2026-09-13 14:05 CDT`, the full
  date, time and zone. This is the screen people open to find out *when*.

### Docs and tests

- README: a new paragraph in the done/reopen section covering the row and view
